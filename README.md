# Zen Cart - Redsys Payment Module
Zen Cart payment module for the Redsys (Spain) payment gateway, by redirección.

The Zen Cart module 3.1.1 offered by Redsys has bugs, is missing core functionality, and is very out of date, so do not even bother installing it.

This readme is here as a placeholder for users to know that an up-to-date, encapsulated version does exist, working with Zen Cart 2.2.2 and 3.0.

If you want a copy, send me a pm via the forum:
https://www.zen-cart.com/threads/196416

## Issues
Although there were many issues found 20 years ago when first de-lousing the module, they are not documented here, only ones that have cropped up 2026+ as the development of ZC3 tightens things up.
